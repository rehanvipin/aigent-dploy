# Requesting emergency-trauma medical records — what to ask for

Emergency and trauma records are split across departments, and a "complete"
package is easy to under-request. When following up on records for an ER or
trauma visit, make sure the request covers **all** of:

- the **ED provider notes** (triage note, attending notes, discharge summary),
- **imaging** — both the images *and* the radiology reports (they are billed
  and stored separately; a release often includes only the reports),
- **labs** and medication administration records (MAR),
- **EMS / ambulance run sheet**, if the client arrived by ambulance — this is
  a *separate provider* (the ambulance company or fire department), not the
  hospital, and needs its own request,
- **billing / itemized statement** — stored in a different system from the
  clinical chart; ask for it explicitly or you will get the chart only.

Terminology you will hear on the phone: "HIM" (Health Information Management —
the desk that releases records), "ROI" (release of information), "encounter"
(one visit; a client may have several). A HIPAA authorization on file is
usually enough; some hospitals also want their own ROI form signed.

If the visit involved a trauma activation, say so — trauma records are flagged
and sometimes released faster when the activation is mentioned.
